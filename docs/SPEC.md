# OpenPin 功能规格（SPEC）

> OpenPin 是一款 **完全免费、开源（MIT）** 的 Windows 截图 / 贴图工具，功能对标 PixPin。
> 本文件是开发的唯一需求来源。每条需求有编号（如 `CAP-04`）和优先级：
>
> - **P0**：v0.1 必须完成
> - **P1**：v0.2 应该完成
> - **P2**：以后再说 / 需要额外资源
>
> 范围：**仅 Windows 10 1809+ / Windows 11，x64**。**不做**账号、会员、云同步、在线更新服务器。
> 所有功能本地运行、离线可用；不上传任何数据。

默认快捷键与 PixPin 保持一致，方便用户迁移：截图 `Ctrl+1`、贴图 `Ctrl+2`、恢复贴图 `Ctrl+3`、自定义截图 `Alt+1`、切换贴图组 `` Ctrl+` ``。
